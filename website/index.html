开始使用

Guide

gox-ui 是 Element Plus 风格的 Gox 原生 GUI 组件库 —— 跑在 Gox gfx 渲染内核上（不是 WebView）， 桌面（Windows / macOS / Linux）与移动（Android / iOS / 鸿蒙）同一份代码。 组件细节的多端差异（触控命中、断点、安全区）由 adaptive.js 自动处理。

桌面 Windows 980×820 · 居中弹窗 / 横向步骤 / hover 提示
移动 触控档 400×720 · 底部面板 / 纵向步骤 / ≥44px 命中
$ npm install gox-ui 复制
app.jsx — 一个最小的完整应用：
import { h, render } from "gx/gfx";
import { createSignal } from "gx/solid";
import { GxButton, GxInput, GxCard, GxMessage, GxMessageHost } from "gox-ui";

const [name, setName] = createSignal("");

render(
  <window title="Hello" width={420} height={280}>
    <column gap={16} padding={24} font={14}>
      <GxCard header="问候">
        <GxInput placeholder="你的名字" model={name} clearable />
        <GxButton type="primary" onClick={() => GxMessage.success(`你好, ${name()}!`)}>打招呼</GxButton>
      </GxCard>
      <GxMessageHost />
    </column>
  </window>
);

多端自适应

Adaptive

所有端差异收敛在 src/adaptive.js。数据源：gx/device（平台形态）+ gx/viewport（断点 / 安全区 / 键盘）。断点跟随内核口径，窗口 resize、折叠屏展开自动重算。

差异点桌面（鼠标档）移动（触控档）
控件高度40 / 32 / 2452 / 44 / 44（命中下限 44 · WCAG 2.5.5）
Dialog居中卡片底部动作面板
Steps横向compact（<600dp）自动纵向
CheckboxGroup横向换行纵向整行
Tooltiphover 提示不渲染（信息走 label）
